# GTC Kuwait: demo redesign
Open index.html. Static HTML/CSS/JS, no build needed. Regenerate with `python3 build.py`.

Colours (charcoal, red, olive-gold) are sampled from screenshots of the live site and live in :root of assets/style.css. Confirm against GTC's official brand files before real use.

## Problems on the current site this addresses
- Careers page shows a raw `[wpjb_jobs_list]` shortcode instead of a job list
- Pages last edited 2016-2021; footer says 2023
- Events and news split across several pages
- Google Maps error dialog on the Contact page
- Stats block wraps awkwardly on phones; Clients section is empty
- No search, filtering or mobile-first navigation
